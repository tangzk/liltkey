# LiltKey v0.5.1

SenseVoice final correction is now **enabled by default**. Setup automatically prepares the model, so new installations keep streaming drafts and refine each segment before committing. An explicit `streaming_refine = false` preference is preserved.

**定稿校正改为默认开启。** 新安装直接使用“流式预览 + SenseVoice 定稿校正”，无须手动下载校正模型或修改配置。

## 更新内容

- 默认配置及省略 `streaming_refine` 的旧配置均开启校正。明确设置 `false` 时仍保留关闭状态。
- 安装器自动下载并校验 SenseVoice，遵守自定义模型目录；所需模型就绪后再启动服务。
- 手动下载命令也默认准备校正模型；新增 `--no-refinement` 用于只准备原流式模型。原 `--with-refinement` 参数继续兼容。
- 校正失败仍回退至流式识别，快捷键和分句行为保持不变。
- 中英文网站与说明同步更新；模型对比继续放在独立页面，首页仅保留简短入口。

## 安装或升级

适用于 Ubuntu 26.04 / amd64 / Fcitx5 5.1.19 或更新版本：

```bash
sudo apt install ./fcitx5-voice_0.5.1_amd64.deb
```

首次安装需联网准备依赖和约 490 MiB 模型文件。已有模型会校验后复用。安装会重启输入法和识别服务，请先完成正在输入的内容；个人配置及外观偏好保留。准备完成后听写仍无需联网。

如果旧配置明确写有 `streaming_refine = false`，请改为 `true` 后运行 `fcitx5-voice-setup`，安装器会准备所需模型并重启服务。

## 验证

149 项 Python 测试、5 项 C++ 测试、16 项网页动效测试通过。覆盖新安装默认启用、旧配置省略选项、明确关闭、自定义目录以及下载选项兼容。未进行全新虚拟机联网安装验收。

附带 `SHA256SUMS`；可用 `sha256sum -c SHA256SUMS` 校验安装包。
