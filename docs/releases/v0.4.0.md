# LiltKey v0.4.0

新增 Ctrl+Alt 长按录音：按住说话，松开结束。本次 deb 同时包含重新编译的 Fcitx5 原生插件和支持持续录音的 Python 服务。此前的 v0.3.0-3 安装包不包含此功能。

## 新功能

- 长按 `Ctrl+Alt` 约 300 毫秒开始录音，松开任意一个键结束并处理尾句；左右 Ctrl、Alt 和按键先后顺序均支持，AltGr 不属于 Alt。
- 按住期间可持续说多句话，不受默认 30 秒录音上限限制。默认流式模式继续在停顿后补充标点并提交。
- 短按组合键或在等待期间按其他键不会启动录音；切换焦点、重置输入状态和取消会话会释放录音。
- 保留 `Ctrl+Alt+V` 切换开始／结束录音，该方式默认每次最多 30 秒；`Esc` 放弃未提交内容，已提交文字保留。
- README、宣传页、演示状态及安装就绪提示同步介绍两种录音方式。

## 安装或升级

目标系统为 **Ubuntu 26.04 / amd64（x86-64）/ Fcitx5 5.1.19 或更新版本**。下载附件 `fcitx5-voice_0.4.0_amd64.deb`，使用软件中心安装，或运行：

```bash
sudo apt install ./fcitx5-voice_0.4.0_amd64.deb
```

安装前请完成正在输入的内容。安装会自动配置用户运行环境和语音服务，将默认输入法设为 Fcitx5 并重启；保留已有语音配置、拼音配置和个人外观偏好。原生插件与服务需一起升级，安装此包会同时更新两者。

首次保持联网，等待约 260 MiB 模型和 Python 依赖准备完成，收到“语音输入已就绪”通知后注销并重新登录。清透浅色主题继续随包提供，首次配置默认启用，升级不会重置后来的外观选择。

同时下载 `SHA256SUMS` 后可运行 `sha256sum -c SHA256SUMS` 核对安装包。
