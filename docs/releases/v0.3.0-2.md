# LiltKey v0.3.0-2

本次安装包修订将首次配置合并到 deb 安装流程：安装后自动准备用户运行环境、下载模型并启用服务，正常安装无需再手动运行 setup、download-model 或 systemctl 命令。语音功能版本仍为 0.3.0。

## 下载与安装

从本次 Release 的附件下载 `fcitx5-voice_0.3.0-2_amd64.deb`。目标环境为 **Ubuntu 26.04 / amd64（x86-64）/ Fcitx5 5.1.19 或更新版本**；其他 Linux 发行版与 ARM 设备需自行构建并验证。

1. 完成正在输入的内容，用软件中心打开安装包，或在下载目录运行：

   ```bash
   sudo apt install ./fcitx5-voice_0.3.0-2_amd64.deb
   ```

2. 保持联网，等待“语音输入已就绪”通知。首次需要下载约 260 MiB 默认模型，另需安装 Python 依赖。
3. 注销并重新登录，在接入 Fcitx5 的文本框按 `Ctrl+Alt+V` 开始或结束听写。

自动配置会将默认输入法设为 Fcitx5 并重启输入法，保留已有拼音、语音配置和校验通过的模型。安装期间没有图形桌面会话时，下次登录开始初始化；失败后每 5 分钟重试。准备完成后，听写无需联网。

同时下载 `SHA256SUMS`，在同一目录运行 `sha256sum -c SHA256SUMS` 可核对安装包。安装或升级均使用上述 deb；无需先卸载旧包。进度与故障排查见[高级使用与维护](https://github.com/tangzk/liltkey/blob/main/docs/advanced-usage.md#安装与自动配置)。

## 其他更新

- 宣传页同步自动安装步骤、下载地址及初始化失败排查说明。
- 首页输入演示循环播放，可单独暂停；离开视口或切到后台时停止，返回后恢复，遵循系统减少动态效果设置。
- 安装包包含原生插件、服务与设置脚本、MIT 和第三方许可文件，不包含模型权重或第三方 Python 依赖。依赖和模型仍遵循各自许可。

## 验证范围

112 项 Python 测试、4 项 C++ 测试通过，涵盖安装脚本、自动配置状态、协议及隔离的 Fcitx5 输入上下文；另验证宣传页循环播放与暂停逻辑。已检查实际 deb 内容及 apt 模拟依赖解析。

自动配置的系统命令与下载步骤通过测试替身验证，尚未在全新虚拟机完成联网安装验收；各桌面应用的真实麦克风识别效果仍需实机确认。
