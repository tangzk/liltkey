# LiltKey v0.5.0

Optional local SenseVoice refinement: keep streaming drafts visible, then correct each segment before committing it. Off by default; existing shortcuts and settings are preserved. The website now includes a concise six-model CPU comparison in English and Chinese.

新增可选的本地 SenseVoice 定稿校正：边说边显示流式草稿，停顿或松键时校正该段音频，再提交最终文字。宣传网站同步加入六款模型的精简对比和方案取舍。

## 更新内容

- 使用已有 Zipformer 提供流式预览，SenseVoice 对尚未提交的音频重新识别，并使用自身标点；不回改已提交正文。
- 模型加载失败或校正出错时回退至原流式识别，保留预读内容；取消、失焦后不提交迟到结果。
- 每段最多在内存保留 20 秒音频，达到上限自动定稿；不保存或上传录音。硬分段可能影响边界词。
- 增加下载、安装和诊断支持。功能默认关闭，不改变旧安装的模型依赖；Ctrl+Alt 长按、Ctrl+Alt+V 切换和 Esc 取消保持不变。

## 安装或升级

适用于 **Ubuntu 26.04 / amd64（x86-64）/ Fcitx5 5.1.19 或更新版本**。下载附件并安装：

```bash
sudo apt install ./fcitx5-voice_0.5.0_amd64.deb
```

安装会自动准备用户运行环境、重启输入法及服务，保留个人语音配置、拼音和外观偏好；请先完成正在输入的内容。首次安装需联网下载默认约 260 MiB 模型和依赖，收到“语音输入已就绪”通知后注销并重新登录。

## 开启定稿校正

升级后先准备额外的 SenseVoice 模型：

```bash
fcitx5-voice-download-model --with-refinement
```

在 `~/.config/fcitx5-voice/config.toml` 中设置以下项目，保留其他个人设置，避免重复同名配置：

```toml
backend = "streaming"
streaming_refine = true
```

确认模型就绪并重启服务：

```bash
fcitx5-voice doctor
systemctl --user restart fcitx5-voice
```

自定义模型目录和关闭方法见[高级使用](https://github.com/tangzk/liltkey/blob/v0.5.0/docs/advanced-usage.md#流式预览与快速定稿校正)。

## 测试与对比

148 项 Python 测试、5 项 C++ 测试和 16 项网页动效测试通过。使用全新 Release 构建目录重新编译插件，解包核对发布包中的版本、插件和服务源码，并验证包内识别服务及插件。

在 i7-14700K、CPU 4 线程上对比六款模型，使用 40 段中文和 20 段英文公开 FLEURS 录音。SenseVoice 整句计算中位数约 0.18 秒；三个产品流程回放场景停止后约 40–199 毫秒完成。两类时间口径不同，均不代表真实麦克风和界面延迟或所有录音的速度保证。流式预览本身的识别质量没有改变，未进行全新虚拟机联网安装及用户真实口述验收。
