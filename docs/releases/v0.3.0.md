# LiltKey v0.3.0

LiltKey 是 Linux / Fcitx5 的本地语音输入工具，支持中英混合听写、流式预览、停顿分句和本地标点恢复。原创代码采用 MIT 许可证。

## 下载与安装

从本次 Release 的附件下载 `fcitx5-voice_0.3.0_amd64.deb`。预编译包的验证目标为 **Ubuntu 26.04 LTS / amd64（x86-64）/ Fcitx5 5.1.19**，需要桌面已配置使用 Fcitx5。其他发行版、旧版 Ubuntu 和 ARM 设备需自行构建并验证。

在下载目录打开终端：

```bash
sudo apt install ./fcitx5-voice_0.3.0_amd64.deb
fcitx5-voice-setup
fcitx5-voice-download-model
fcitx5-voice doctor
systemctl --user daemon-reload
systemctl --user enable --now fcitx5-voice
```

只有第一条命令使用 sudo。其余命令使用当前桌面用户执行，最后从 Fcitx5 托盘菜单重启输入法。将光标放入文本框，按 `Ctrl+Alt+V` 开始或结束听写；按 Esc 放弃未提交内容。

同时下载 `SHA256SUMS` 后，可在同一目录运行 `sha256sum -c SHA256SUMS` 核对安装包。

## 安装包内容

- 已编译的 Fcitx5 插件、本地识别服务源码及用户级设置工具。
- MIT 许可证、第三方版权声明和模型许可说明。
- 不包含模型权重或 Python 第三方依赖。首次 setup/download 需要联网，默认下载中英流式模型与标点模型；准备完成后听写无需联网。

安装 `.deb` 本身不会自动下载模型、启动服务或重启输入法。SenseVoice 离线模式为可选功能，需要另行配置和下载模型。第三方软件及模型保留各自许可，详见仓库的 `THIRD_PARTY_NOTICES.md` 和 `MODEL_LICENSES.md`。

## 验证范围

本次通过 87 项 Python 测试和 4 项 C++ 测试，并检查用户安装、卸载和安装包内的许可文件。测试涵盖合成音频、协议、状态和隔离的 Fcitx5 输入上下文；各桌面应用的真实麦克风识别质量尚未逐一验收。
