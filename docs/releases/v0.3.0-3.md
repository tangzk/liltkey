# LiltKey v0.3.0-3

安装包默认附带 LiltKey 清透浅色主题：白色圆角面板、柔和阴影、蓝色选中项和更清晰的字体。README 新增真实 Fcitx5 候选框截图。语音功能版本仍为 0.3.0。

## 安装

下载附件 `fcitx5-voice_0.3.0-3_amd64.deb`，使用软件中心安装，或在下载目录运行：

```bash
sudo apt install ./fcitx5-voice_0.3.0-3_amd64.deb
```

目标系统为 Ubuntu 26.04 amd64，Fcitx5 5.1.19 或更新版本。安装前请完成正在输入的内容；自动配置会将默认输入法设为 Fcitx5 并重启，保留现有拼音与语音配置。首次保持联网，等待约 260 MiB 模型和 Python 依赖准备完成，收到“语音输入已就绪”通知后注销并重新登录。默认 `Ctrl+Alt+V` 开始／结束语音输入。

同时下载 `SHA256SUMS` 后可运行 `sha256sum -c SHA256SUMS` 核对安装包。

## 主题与升级

- 首次配置自动将默认浅色主题切换为 LiltKey；已有自定义主题、深色偏好、非默认字体与候选词排列方式保留。
- 后续升级更新主题资源，不会重置用户后来选择的主题或字体。
- 附带六张原创 PNG 和完整主题配置；推荐安装 `fonts-noto-cjk`。运行不需要 Pillow。
- 主题在用户目录保留一份，卸载语音功能后仍可使用；迁移前的已有外观配置会备份，详见[主题与恢复](https://github.com/tangzk/liltkey/blob/main/themes/README.md)。
- 主题适用于 Fcitx5 经典界面，Kimpanel 和桌面绘制的托盘菜单使用各自外观。

119 项 Python 测试、4 项 C++ 测试、10 项网页动效测试通过。验证覆盖首次安装、默认主题迁移、自定义及深色偏好保留、重复安装、主题资源升级、卸载保留，以及从实际解包后的 deb 执行用户安装。原生插件沿用已验证的 0.3.0 构建；模型与第三方 Python 依赖仍在安装后下载。
