# 截图来源

`fcitx5-light-theme.png` 于 2026-09-18 截取自真实 Fcitx5 5.1.19 经典界面和 GTK3 输入框。

在隔离的 Xvfb/X11、D-Bus 会话和临时 HOME/XDG 目录中，通过本项目 `install_theme` 安装默认主题后启动 Fcitx5，以 XTest 输入测试拼音 `xiexiaxiangfa`。使用 xcompmgr 的正常透明合成模式，GDK 直接截取 900 × 430 显示区域，未拼接或后期修改候选框。周围的 GTK 窗口仅用于展示输入效果，不是额外的 LiltKey 桌面应用。

截图不包含用户桌面、真实口述或私人文档，没有访问麦克风。字体缩放和候选词可能随用户环境变化。
